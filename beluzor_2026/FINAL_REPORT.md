## 🎯 КЛЮЧАВЫЯ МАГЧЫМАСЦІ

### 1. Гібрыдны пошук (Hybrid Search)
- **BM25 (Sparse)**: Дакладны пошук па датах, імёнах, назвах
- **Dense Vector**: Семантычны пошук па сэнсе
- **RRF (Reciprocal Rank Fusion)**: Аб'яднанне вынікаў

### 2. NLP для беларускай мовы
- **Лематызацыя**: Прывядзенне слоў да нармальнай формы
- **NER**: Распазнаванне асоб, дат, месцаў, законаў
- **Вызначэнне правапісу**: Аўтаматычнае распазнаванне наркамівкі/тарашкевіцы

### 3. GraphRAG (Граф ведаў)
- **Сувязі**: [Скарына] → (нарадзіўся ў) → [Полацк]
- **Візуалізацыя**: Інтэрактыўныя графы Plotly
- **Пошук шляхоў**: Адказ на складаныя пытанні тыпу "Як Скарына звязаны з Полацкам?"

### 4. Рэранжыраванне
- **BGE-Reranker-v2-m3**: Фільтрацыя Top-50 → Top-5
- **Эканомія кантэксту**: Менш токенаў для LLM
- **Павышэнне дакладнасці**: Лепшыя факты для генерацыі

### 5. QLoRA Навучанне
- **Эфектыўнае даобучэнне**: 4-bit квантаванне
- **Пашырэнне токенизатора**: Беларускія словы як адзіныя токены
- **Continual Pre-training**: Захаванне ведаў базовай мадэлі
