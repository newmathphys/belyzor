# 🇧🇾 БелУзор v2026: Інтэлектуальная сістэма па гісторыі Беларусі

Гэта дэманстрацыйная версія перадавой сістэмы пошуку і аналізу гістарычных дадзеных, якая выкарыстоўвае найноўшыя тэхналогіі 2026 года.

## 🔥 Ключавыя магчымасці

- **Гібрыдны пошук (Hybrid Search)**: Камбінацыя BM25 (sparse) і вектарнага пошуку (dense) з алгарытмам RRF для максімальнай дакладнасці
- **GraphRAG**: Пабудова графа ведаў для выяўлення сувязей паміж гістарычнымі асобамі, падзеямі і месцамі
- **NLP для беларускай мовы**: Распазнаванне сутнасцей (NER), лематызацыя, вызначэнне правапісу (наркамівка/тарашкевіца)
- **Рэранжыраванне (Reranking)**: Выкарыстанне крос-энкодараў для фільтрацыі найбольш рэлевантных фактаў
- **Інтэрактыўная візуалізацыя**: Графы сувязяў у рэальным часе з дапамогай Plotly

## 📚 Як карыстацца

1. Увядзіце пытанне па гісторыі Беларусі ў поле ўводу
2. Націсніце "Знайсці і адказаць"
3. Атрымайце адказ са спасылкамі на крыніцы
4. Даследуйце граф ведаў для разумення сувязей
5. Праверце NLP-аналіз для выяўленых сутнасцей

## 🛠 Тэхналагічны стэк

- **Frontend**: Gradio 4.x
- **Візуалізацыя**: Plotly, NetworkX
- **NLP**: SpaCy, SacreMoses (підтрымка беларускай мовы)
- **Вектарны пошук**: Sentence Transformers (BGE-M3, E5)
- **LLM**: Інтэграцыя з Llama 3.2, GPT-4o (у поўнай версіі)
